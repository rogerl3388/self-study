# cs61a_files

Repo for files generated/edited during self-study of UC Berkeley CS61A content. These mainly consist of the homework, lab, and project files

The folders have an .ok file and a file named "ok"; these are the local autograder supplied by the class for students to confirm their work. However, it requires an active UC berkeley student email; in lieu of testing, I simply used the doctest module and added in my test cases as needed
